Flow guide

  1. Connect MetaMask and switch to Polygon Amoy.
  2. Register a collection if you want to group multiple images.
  3. Hash the original file, encrypt it through the oracle service, then register the image on-chain.
  4. Configure a license price as the current image owner.
  5. Buy the license from a buyer wallet and ask the oracle for an encrypted download token.
  6. Let the image-vector-service record model and index hashes for auditability.
